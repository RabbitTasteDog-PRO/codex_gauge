# v0.4.0 — 코덱스와 클로드 한도를 한눈에 🐾

## 새로 추가했어요

- 남은 한도 카드 아래에 **한도별 게이지** 목록이 생겼어요. 서버가 알려주는 한도마다 남은 %, 진행 막대, 초기화 시각이 보여요.
- **Claude 한도**도 함께 보여요. 5시간 한도와 주간 한도이고, 계정에 따라 Opus·Sonnet 주간 한도도 나와요.
- 목록에서 **체크한 한도**가 메뉴 막대 게이지와 큰 숫자로 표시돼요. 선택은 앱을 다시 켜도 유지돼요.
- 패널 상단에 **앱 버전**이 보여요.

## 알아두세요

- Claude 한도는 이 맥의 Claude Code 로그인 정보를 사용해요. 처음 실행할 때 키체인 접근 창이 뜨면 **항상 허용**을 눌러 주세요. 로그인 정보는 저장하거나 기록하지 않아요.
- Claude 사용량 조회 주소는 공식 공개 API가 아니라서 바뀌면 동작하지 않을 수 있어요.
- 한도 선택 메뉴는 체크박스로 바뀌어 없어졌어요.

## 설치·업데이트

1. 기존 Codex Gauge가 실행 중이면 종료해요.
2. `CodexGauge-0.4.0-macos-arm64.zip`을 내려받아 압축을 풀어요.
3. `Codex Gauge.app`을 응용 프로그램 폴더에 넣어 교체한 뒤 실행해요.
