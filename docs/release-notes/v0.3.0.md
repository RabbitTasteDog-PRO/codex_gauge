# v0.3.0 — 한도가 차면 고양이가 게이지를 툭툭 쳐요 🐾

한도가 초기화되면 고양이가 먼저 알려줘요.
호기심이 생긴 고양이가 게이지를 툭툭 건드려요.

## 새로 추가했어요

- 사용 중이던 한도가 초기화되어 **남은 한도가 100%**가 되면, 고양이가 **초록색 게이지**를 툭툭 쳐요.
- 발이 닿는 순간 게이지도 살짝 움찔해요.
- 고양이를 **클릭**하거나 남은 한도가 **100% 미만**이 되면 평소 고양이·밥그릇과 **파란색 게이지**로 돌아와요.
- 창이 이미 열려 있다면 **“눌러서 진정시키기”** 버튼으로도 알림을 해제할 수 있어요.
- 한도가 부족할 때의 주황색·빨간색 경고는 유지돼요.

앱을 처음 켰을 때 보이는 100%는 초기화로 오인하지 않아요. 같은 계정에서 새로 조회한 한도 변화를 확인해요.

## 가볍게 움직여요

- 기존 초당 5프레임과 이미지 캐시를 유지해요.
- 축하 애니메이션과 클릭으로 사용량을 추가 조회하지 않아요.
- 화면 꺼짐·비활성 세션·절전 모드·동작 줄이기 처리를 유지해요.
- 기능 테스트 **70개를 통과**했어요.

개발 맥의 가상 데이터 미리보기에서 30초간 측정한 CPU는 평균 **약 1.6%**, 최고 **약 2.6%**였어요. 환경에 따라 달라질 수 있어요.

## 설치·업데이트

1. 기존 Codex Gauge가 실행 중이면 종료해요.
2. `CodexGauge-0.3.0-macos-arm64.zip`을 내려받아 압축을 풀어요.
3. `Codex Gauge.app`을 응용 프로그램 폴더에 넣어 교체한 뒤 실행해요.

macOS 13 이상 · Apple Silicon(M1 이상)용이에요. Codex CLI가 별도로 필요해요.
