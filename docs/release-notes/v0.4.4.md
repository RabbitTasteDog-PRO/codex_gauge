# v0.4.4 — 클로드 한도를 1분마다 확인해요 🐈

Claude 한도 조회 주기를 1분으로 정리하고, 요청 제한이 발생했을 때 이전 조회 값과 재조회 가능 시간을 구분해 보여줘요.

## 달라졌어요

- Claude 사용량을 정상적으로 조회할 때 약 **1분 간격**으로 확인해요. Codex 조회가 지연되어도 Claude는 별도로 조회해요.
- 수동 새로고침도 직전 Claude 조회 후 1분이 지나기 전에는 중복 요청하지 않아요.
- 서버가 **429 요청 제한**을 보내면 최소 5분을 기다려요. 제한이 반복되거나 서버가 더 긴 시간을 지정하면 더 기다리고, 앱을 다시 열어도 대기 시간이 유지돼요.
- 요청 제한 중 마지막으로 확인한 Claude 한도가 있으면 **이전 값**이라고 표시해요. 로그인 만료 등 다른 조회 오류는 안내하고 오래된 값을 숨겨요.
- 간결한 패널과 Codex·Claude 한도별 게이지를 다시 포함했어요.

## 알아두세요

조회 간격을 조정해도 Claude 서버의 요청 제한이 발생할 수 있어요. Claude 로그인은 앱에서 자동 갱신하지 않으므로 만료되면 Claude Code에서 갱신해 주세요. Claude 사용량 조회 주소는 공식 공개 API가 아니어서 변경될 수 있어요.

## 설치·업데이트

1. 실행 중인 Codex Gauge를 종료해요.
2. `CodexGauge-0.4.4-macos-arm64.zip`을 내려받아 압축을 풀어요.
3. `Codex Gauge.app`을 응용 프로그램 폴더에 넣어 기존 앱을 교체한 뒤 실행해요.

Apple Silicon Mac용이며 Codex CLI는 별도로 설치해야 해요. 앱은 개인용 임시 서명을 사용하며 Apple 공증은 적용되지 않았어요.
