# Codex Gauge 0.2.0 — 조용한 고양이

달리던 고양이가 가만히 앉아 숨 쉬고 눈을 깜빡여요.

- 남은 한도에 따라 고양이 체형과 표정, 사료가 5단계로 바뀝니다.
- 각 단계는 32프레임으로, 한 번의 아이들 주기는 약 6.4초입니다.
- 밥그릇과 사료는 고정해서 눈에 덜 부산스럽게 보이도록 했습니다.
- 동작 줄이기 설정, 잠자기와 비활성 세션에서는 애니메이션을 멈춥니다.

macOS 13 이상, Apple Silicon(M1 이상)용입니다. Codex CLI는 별도로 설치하고 내 ChatGPT 계정으로 로그인해야 합니다.

앱 다운로드: **Assets의 `CodexGauge-0.2.0-macos-arm64.zip`**을 받아 압축을 풀고 `Codex Gauge.app`을 응용 프로그램 폴더에 넣으세요.

개발자 인증·공증이 없는 개인 앱입니다. 출처를 확인한 뒤 macOS에서 실행을 허용해야 할 수 있습니다. Codex CLI·IDE 확장과 로그인을 공유하므로 앱에서 로그아웃하면 그 로그인도 해제됩니다.
