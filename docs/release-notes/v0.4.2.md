# v0.4.2 — 더 작고 깔끔하게 보여요 🐈

> **사용 중단 권장:** v0.4.1~v0.4.3에서 Claude 세션 및 사용량 표시 문제가 보고되어 [v0.4.0](https://github.com/RabbitTasteDog-PRO/codex_gauge/releases/tag/v0.4.0)을 권장합니다.

남은 한도와 토큰 사용량을 간결하게 정리하고, 패널 아래쪽 버튼이 잘리던 문제를 고쳤어요.

## 달라졌어요

- **남은 한도 표시를 줄였어요.** 숫자를 36pt에서 22pt로 줄이고, 중복된 초기화 정보는 한도별 목록으로 정리했어요.
- **토큰 사용량은 한 줄로 보여요.** 누적·최근 일별 수치를 만·억 단위로 요약해요. 숫자에 마우스를 올리면 정확한 토큰 수를 볼 수 있고, 최근 일별 기록의 서비스 기준 날짜도 표시해요.
- **패널이 더 작아졌어요.** 기본 높이는 480pt예요. 프로필과 Codex·Claude 한도 목록, 메뉴 막대에 표시할 한도 선택은 유지했어요.
- **하단 버튼이 잘리지 않아요.** 화면과 팝오버의 높이를 맞추고, 표시되는 모니터의 사용 가능한 높이 안에 배치해요. 제목과 새로고침·설정·종료 버튼은 고정하고, 공간이 부족하면 가운데만 스크롤돼요.

## 확인했어요

- 로컬 macOS에서 기능 테스트 73개를 통과했어요.
- 화면 간소화 후 실제 Codex·Claude 한도 표시, 선택 전환과 하단 버튼 배치를 확인했어요.
- 배포 ZIP의 체크섬과 압축 해제한 앱의 서명·버전·리소스를 확인했어요.

## 설치·업데이트

1. 실행 중인 Codex Gauge를 종료해요.
2. `CodexGauge-0.4.2-macos-arm64.zip`을 내려받아 압축을 풀어요.
3. `Codex Gauge.app`을 응용 프로그램 폴더에 넣어 기존 앱을 교체한 뒤 실행해요.

Apple Silicon Mac용이며, Codex CLI는 별도로 설치되어 있어야 해요. 개인용 임시 서명을 사용하며 Apple 공증은 적용되지 않았어요.

Claude 한도는 기존 Claude Code 구독 로그인을 사용해요. 로그인이 만료되면 Claude Code에서 갱신한 뒤 새로고침해 주세요. Claude 조회 주소는 공식 공개 API가 아니어서 서비스 변경 시 동작하지 않을 수 있어요.
