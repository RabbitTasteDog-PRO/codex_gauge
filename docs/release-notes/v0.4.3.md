# v0.4.3 — 클로드 한도를 더 정확하게 보여요 🐈

Claude 로그인이 만료됐을 때 오래된 한도와 초기화 시각이 현재 값처럼 남아 있던 문제를 고쳤어요.

## 달라졌어요

- Claude 조회에 실패하면 이전 Claude 한도와 초기화 시각을 숨기고 오류를 표시해요.
- 메뉴 막대에 Claude 한도를 선택해 둔 상태에서 조회가 실패하면 확인 불가 상태로 표시해요. Codex 한도를 대신 보여주지 않아요.
- Claude 조회가 다시 성공하면 선택해 둔 Claude 한도를 다시 표시해요.
- Codex 연결 상태와 갱신 시각에 서비스 이름을 표시해 Claude 상태와 구분하기 쉽게 했어요.

## 알아두세요

Claude 로그인은 앱에서 자동으로 갱신하지 않아요. 로그인이 만료되면 터미널에서 `claude`를 실행해 갱신한 뒤 앱에서 새로고침해 주세요. Claude 사용량 조회 주소는 공식 공개 API가 아니어서 서비스 변경 시 동작하지 않을 수 있어요.

## 설치·업데이트

1. 실행 중인 Codex Gauge를 종료해요.
2. `CodexGauge-0.4.3-macos-arm64.zip`을 내려받아 압축을 풀어요.
3. `Codex Gauge.app`을 응용 프로그램 폴더에 넣어 기존 앱을 교체한 뒤 실행해요.

Apple Silicon Mac용이며 Codex CLI는 별도로 설치해야 해요. 앱은 개인용 임시 서명을 사용하며 Apple 공증은 적용되지 않았어요.
