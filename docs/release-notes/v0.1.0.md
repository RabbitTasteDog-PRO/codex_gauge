# Codex Gauge 0.1.0 — Preview

macOS 메뉴 막대에서 도트 고양이, 게이지와 남은 퍼센트로 Codex 사용량을 확인합니다.

## 다운로드

Assets의 **CodexGauge-0.1.0-macos-arm64.zip**을 받으세요. GitHub가 자동으로 제공하는 Source code ZIP은 실행 앱이 아닌 소스 코드입니다.

## 사용 조건

- Apple Silicon Mac(M1 이상), macOS 13 이상
- Codex CLI 별도 설치 필요: [공식 설치 안내](https://learn.chatgpt.com/docs/codex/cli)
- 본인의 ChatGPT 계정으로 로그인
- 개인용 임시 서명 버전이며 Apple 공증은 적용되지 않았습니다. macOS가 실행을 차단할 수 있습니다. 출처를 확인한 뒤 [Apple 안내](https://support.apple.com/en-ie/102445)를 따라 실행하세요.

## 실행

1. ZIP을 압축 해제합니다.
2. `Codex Gauge.app`을 응용 프로그램 폴더로 옮기고 더블 클릭합니다.
3. 미로그인 상태라면 열린 브라우저에서 로그인을 완료합니다.
4. 상단 메뉴 막대의 고양이를 클릭해 사용량을 확인합니다.

로그아웃이 완료되면 저장된 사용량을 지우고 앱을 종료합니다. 기존 Codex CLI·IDE 확장과 인증을 공유하므로 해당 도구에서도 다시 로그인해야 할 수 있습니다.

파일 확인은 ZIP과 `SHA256SUMS.txt`를 같은 폴더에 둔 뒤 터미널에서 실행합니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```

설치·로그인 화면과 상세 사용법은 저장소 README를 참고하세요.
