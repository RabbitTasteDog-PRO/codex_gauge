## 생성 프롬프트

+Use case: stylized-concept
Asset type: original character design and running-animation concept sheet for a macOS menu-bar quota app called Codex Gauge.
Primary request: Create one polished character sheet showing the SAME cute cat progressively getting slimmer as available quota decreases. This is an ORIGINAL mascot, not RunCat or Nyan Cat. Make the character very legible at 24–32 pixels tall.
Composition: dark charcoal solid background, landscape sheet, precisely four horizontal rows and four columns, a total of 16 isolated white cat silhouettes. Each row is a weight stage; each column is a sequential run-cycle pose. Generous consistent spacing, same ground baseline within each row. No decorative UI, no real screenshot, no title, no text, no percentage labels, no watermark.
Subject and identity: A charming side-profile cat facing RIGHT with tiny pointed ears, short muzzle, a very simple dark dot eye punched out of its white silhouette, a gently curved tail trailing LEFT. Same head, ears, facial expression, limb lengths and tail design across all rows. Keep cats wholly inside their cells. The silhouette is clean flat opaque warm white, smooth crisp edges, no gradient, no texture, no hair detail, no realistic fur, no outlines.
Top row: very plump, round and adorably bouncy belly, clearly the fullest body.
Second row: moderately plump and rounded torso.
Third row: normal slim athletic torso.
Bottom row: smallest gently slender torso, still healthy and cheerful, NOT skeletal or sick. Head and legs stay same size; only torso and belly volume progressively decrease strongly enough to read at menu-bar size.
Animation: columns 1 through 4 show a coherent continuous running cycle: extended airborne stride, front paw contact and rear legs gathering, compact passing/compressed pose, rear-leg push-off with forelegs reaching. Exactly one cat per cell, no duplicated legs, exactly four legs per cat with overlaps that remain readable, anatomically consistent, friendly energetic motion. Do not copy recognizable existing mascots or include any rainbow trail.
The 4x4 layout should make it immediately apparent that one cat is running and becomes progressively slimmer from the top row to bottom row. It is a design concept sheet for approval, not a final application screenshot.
